Copilot instructions sanity check

Paste a GitHub Copilot repository instructions file below - a repo-wide .github/copilot-instructions.md, a path-specific .github/instructions/NAME.instructions.md, or an AGENTS.md. This runs structural checks against GitHub's documented requirements. It runs entirely in your browser.

Runs entirely in this tab. Close it and your text is gone.

What this checks (and what it can't)

The location, filename, frontmatter, and applyTo checks are structural - verifiable from the file's text against GitHub's documentation for repository custom instructions. The size and content checks are heuristics: they surface things for your review and can be wrong. Whether your instructions are good guidance is a judgment this page doesn't make, and only GitHub's own onboarding template's limits ("no longer than 2 pages", "must not be task specific") back the length warning - it is a guideline, not a hard limit. Token estimates use the rough 4-characters-per-token average and can be off in either direction. This page cannot test whether Copilot actually applies your instructions in a session - no structural check can.
