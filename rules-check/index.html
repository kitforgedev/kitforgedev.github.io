AI rules sanity check

Paste a Cursor .mdc rule, a CLAUDE.md, or an AGENTS.md below. This runs structural checks that catch the most common reasons an assistant silently ignores a rule file. It is a sanity check, not a full linter - and it runs entirely in your browser.

What this checks (and what it can't)

These are structural checks: things that are verifiably right or wrong from the file's text. Whether your rules are good instructions - specific, testable, ordered - is a judgment this page doesn't make. Format references: Cursor's .mdc frontmatter (description, globs, alwaysApply) follows Cursor's public docs; Claude Code loads CLAUDE.md at session start; AGENTS.md is the cross-tool convention adopted by several agents. Token estimates use the rough 4-characters-per-token average and can be off in either direction.
